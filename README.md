# NEURA X - Premium AI Agency Platform

NEURA X is an ultra-premium, futuristic AI agency website and management platform. Built for the next generation of Silicon Valley startups, it features a high-end design, fluid animations, and a robust full-stack architecture.

## 🚀 Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS, GSAP, Framer Motion, Three.js, Lucide Icons.
- **Backend:** Node.js, Express.js, JWT Authentication, Bcrypt, Multer, Helmet, Compression.
- **Database:** MongoDB (via Mongoose).
- **Design:** Glassmorphism, Neon Glow, Custom Animated Cursor, Dark Mode.

## 📁 Project Structure

- `/client`: React frontend with Vite and Tailwind.
- `/server`: Express backend with MVC architecture.
- `.env`: Environment variables (API keys, DB URI).

## 🛠️ Installation & Setup

### 1. Prerequisites
- Node.js (v18+)
- MongoDB (Local or Atlas)

### 2. Backend Setup
```bash
cd server
npm install
# Ensure .env is configured in the root or server folder
npm start # or 'npm run dev' if using nodemon
```

### 3. Frontend Setup
```bash
cd client
npm install
npm run dev
```
